# Talkhub — English Learning Platform (Revised)
A revised and updated build of **Talkhub**, an online English learning platform connecting learners with a native-speaking tutor for real 
conversation practice. This version reflects updates and improvements made after the original Talkhub builds.

## 🌐 LIVE SITE
https://talkhub.eliud-muwowo.com/

## ABOUT
Talkhub helps learners move past textbook grammar and build real conversational confidence in English. The site walks visitors through a simple 
flow: assess your level → choose a package → book a session with a native tutor. This build is a revised iteration of the original Talkhub 
project, with updates to design and/or content.

## BUILT WITH
- HTML5
- CSS3
- CSS Grid & Flexbox
- JavaScript
- Figma → HTML/CSS translation

## PAGES
- **Homepage** — Hero intro, learning flow (assess → choose package), testimonials, "Why Us"
- **About** — Background on Talkhub and its teaching approach
- **Tutors** — Meet the tutor(s)
- **Packages** — Pricing tiers
- **Contact** — Get in touch

## FEATURES
- Fully responsive across all screen sizes
- Revised/updated design based on earlier Talkhub builds
- Testimonial section from real students
- Social links (Instagram, TikTok)
